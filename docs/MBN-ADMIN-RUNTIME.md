# AXIRO Admin cho MBN

Admin hiện quản trị dữ liệu thật từ AXIRO Mini API:

- Khách hàng.
- Sản phẩm tài khoản trò chơi.
- Duyệt/từ chối tin đăng.
- Giao dịch mua và thuê.
- Xác nhận khoản thanh toán giao dịch.
- Xác nhận yêu cầu nạp tiền và cộng số dư.
- Hợp đồng.
- Tranh chấp.

Mọi màn hình sử dụng cùng `VITE_API_URL` với MBN, không có kho dữ liệu riêng.
