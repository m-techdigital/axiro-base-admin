# Known limitations
Mini Admin is a one-admin-many-customers operations console. It intentionally excludes RBAC graphs, company/department/project scope, HR, accounting, BI reports, CRM reservations and generic workflow automation.

Current bounded scope includes customer/product/transaction operations, marketplace trust, wallet/deposit/payout handling, document template operations, generated documents, notifications and audit-oriented history.

Approval, publication and availability are represented through Mini product/transaction status fields. Do not add a separate approval center or parent organization module unless a real MBN consumer is approved.
